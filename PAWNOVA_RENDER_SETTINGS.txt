PAWNOVA RENDER DEPLOY SETTINGS

Build Command:
pip install -r PAWNOVA_REQUIREMENTS.txt

Start Command:
gunicorn PAWNOVA_GATEWAY:app --bind 0.0.0.0:$PORT --workers 1 --threads 8 --timeout 120

Required Environment Variables:
PAWNOVA_ADMIN_PASSWORD=<mật khẩu admin mạnh>
PAWNOVA_SESSION_SECRET=<chuỗi ngẫu nhiên dài, cố định giữa các lần deploy>
PAWNOVA_DB_PATH=/var/data/pawnova.sqlite3
PAWNOVA_DB_BACKUP=true
TELEGRAM_BOT_TOKEN=<token bot hiện có>
TELEGRAM_OWNER_ID=8217369095
PAWNOVA_ENABLE_POLLING=true
PAWNOVA_ENABLE_BOT=true

IMPORTANT: Create/attach a Render Persistent Disk mounted at /var/data BEFORE deploying with PAWNOVA_DB_PATH above. A path environment variable does not create a persistent disk by itself. Do not delete the disk or the pawnova.sqlite3 / pawnova.sqlite3.bak files. Only one service process should poll Telegram getUpdates for a given bot token.
